最終更新: 2026-09-13 ／ 前提: `要件定義書.md` v1.2・`画面設計.md` v1.2

## 0. この文書の使い方

- **残タスクの正本はこれ。** README や他の文書に残タスクを書かない
- 粒度は **1タスク＝半日〜1日**。見積は S（〜2h）／M（半日）／L（1日以上）
- 各タスクに **DoD（完了条件）** を置く。「動いた気がする」で閉じない
- **✅ は DoD を満たして確認済み**のもの。日付と内容は `git log` で辿れる
- **編集は単独で行う**（共同開発は 2026-09-05 当日限りで終了。`分担.md` は履歴）

### 現状（2026-09-06 時点）

`/` `/board` `/kid` `/reward` の4画面、`intake_agent`・`kid_agent`、`points.py`、`calendar_tools.py`。
**Firestore 未導入**。台帳はカレンダー中心のまま。

### 触るときの固定条件

- **`google-genai` を 2.x に上げない。** `google-adk` 1.3.0 が `google-genai<2.0.0` を要求するため、
  上げると**インストールそのものが通らない**。`pip install -U` を安易に打たない（NF-O3）
- `MIMAMORI_DEMO=1` の間はカレンダーに書き込まない（NF-O4）
- **実物のプリント・画面写真は `samples/real/`（Git管理外）へ。**
  コミットされる `samples/` 直下には加工済み・自作のダミーだけ（NF-S7）
