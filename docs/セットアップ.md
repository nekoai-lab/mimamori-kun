## 手順

```bash
# 1. APIキーを取る（GCPプロジェクト不要・無料枠あり）
#    https://aistudio.google.com/apikey

# 2. clone
git clone https://github.com/nekoai-lab/mimamori-kun.git
cd mimamori-kun

# 3. .env
cp .env.example .env
#    GOOGLE_API_KEY= に取ったキーを貼る
#    子の呼び名を変えるなら MIMAMORI_CHILDREN も

# 4. 入れる（バージョンは固定済み。-U で上げないこと）
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 5. 起動
set -a; source .env; set +a
uvicorn main:app --reload --port 8080

# 6. 開く
#    http://localhost:8080/kid    子ども
#    http://localhost:8080/board  親
```

## つまずいたら

| 症状 | 原因 |
|---|---|
| `GOOGLE_API_KEY` が無いと言われる | `set -a; source .env; set +a` を忘れている |
| 起動はするが会話で500 | キーが無効、または無料枠を超えている |
| `/board` は出るが `/kid` の返事が来ない | 会話だけ Gemini が要る。キーの問題 |
| import エラー | `pip install -U` でADKを上げてしまった可能性。`requirements.txt` の版に戻す |

動作確認済み：google-adk 1.3.0 / google-genai 2.22.0 / Python 3.11・3.12

## 台帳の切り替え

`.env` の `MIMAMORI_DEMO` だけで切り替わる。コードは同じ。

| | |
|---|---|
| `MIMAMORI_DEMO=1` | プロセス内のダミー台帳。カレンダーに書かない。再起動で戻る |
| `MIMAMORI_DEMO=0`（または未設定） | 本物の Google カレンダー。`MIMAMORI_CALENDAR_ID` と認証が要る |

**会話の作り込みと、クラウド接続を、切り離して進められる。** これが今日効く。
