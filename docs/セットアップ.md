## 手順

```bash
# 1. APIキーを取る（GCPプロジェクト不要・無料枠あり）
#    https://aistudio.google.com/apikey

# 2. clone
git clone https://github.com/nekoai-lab/mimamori-kun.git
cd mimamori-kun

# 3. .env
cp .env.example .env
#    GOOGLE_API_KEY= に取ったキーを貼る
#    子の呼び名を変えるなら MIMAMORI_CHILDREN も

# 4. 入れる（バージョンは固定済み。-U で上げないこと）
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 5. 起動
set -a; source .env; set +a
uvicorn main:app --reload --port 8080

# 6. 開く
#    http://localhost:8080/kid    子ども
#    http://localhost:8080/board  親
```

## つまずいたら

| 症状 | 原因 |
|---|---|
| `GOOGLE_API_KEY` が無いと言われる | `set -a; source .env; set +a` を忘れている |
| 起動はするが会話で500 | キーが無効、または無料枠を超えている |
| `/board` は出るが `/kid` の返事が来ない | 会話だけ Gemini が要る。キーの問題 |
| import エラー | `pip install -U` でADKを上げてしまった可能性。`requirements.txt` の版に戻す |

動作確認済み：google-adk 1.3.0 / google-genai 2.22.0 / Python 3.11・3.12

## カレンダーの切り替え

`.env` の `MIMAMORI_DEMO` だけで切り替わる。コードは同じ。

| | |
|---|---|
| `MIMAMORI_DEMO=1` | プロセス内のダミー台帳。カレンダーに書かない。再起動で戻る |
| `MIMAMORI_DEMO=0`（または未設定） | 本物の Google カレンダー。`MIMAMORI_CALENDAR_ID` と認証が要る |

**会話の作り込みと、クラウド接続を、切り離して進められる。** これが今日効く。

## ポイント・知らせ・設定の台帳

この台帳の保存先は `MIMAMORI_LEDGER` で選ぶ。`MIMAMORI_DEMO` とは独立している。
ローカルでは未指定または `json` なら `.data/ledger.json` に保存する。
`GOOGLE_CLOUD_PROJECT` や ADC が設定済みでも Firestore のクライアントは作らない。
`MIMAMORI_LEDGER` に `firestore` を明示した場合だけ Firestore を使い、
`GOOGLE_CLOUD_PROJECT` が必須になる。起動時に接続を確認し、設定不足・初期化や接続の失敗では
JSON に切り替えず起動を止める。
Cloud Run（`K_SERVICE` がある環境）は `json` を指定しても Firestore を使う。
空文字を含め、`json`・`firestore` 以外の指定値は両環境で起動エラーになる。

## 親への知らせ（Discord）

子どもが撮って入れたものは**承認を待たずに入る**（D-62）ので、代わりに親へ知らせる。
知らせは必ずアプリの `/board` に残る。**Discord は「スマホにも届く」ようにするための追加**。

### 送り先をつくる（30秒）

1. Discord で家族用サーバーを1つ作る（自分だけでもよい）
2. 知らせを受けるチャンネルを作る（例 `#みまもりくん`）
3. チャンネル名の横の**歯車 → 連携サービス → ウェブフック → 新しいウェブフック**
4. **ウェブフックURLをコピー**
5. そのチャンネルを長押し →「通知設定」→ **すべてのメッセージ** にしておく
   （既定の「@mentionのみ」だと、スマホに出ない）

### アプリに入れる

```bash
# ローカル
MIMAMORI_NOTIFY_WEBHOOK='https://discord.com/api/webhooks/...' uvicorn main:app --reload

# Cloud Run
gcloud run services update mimamorikun \
  --update-secrets=MIMAMORI_NOTIFY_WEBHOOK=mimamori-notify-webhook:latest
```

**URLは秘密**。知っている人は誰でもそのチャンネルに書き込めるので、
リポジトリにも、チャットにも貼らない。Cloud Run では Secret Manager に置く。

### 届くか確かめる

```bash
curl -X POST http://localhost:8080/api/notify/test
```

`#みまもりくん` に「みまもりくん、つながりました」が出れば完了。

| 環境変数 | 役割 |
|---|---|
| `MIMAMORI_NOTIFY_WEBHOOK` | 送り先。未設定なら何も送らない（アプリ内の知らせだけ） |
| `MIMAMORI_NOTIFY_STYLE` | `auto`（既定）/ `discord` / `slack` / `plain`。URLから自動で見分ける |

**送れなくても登録は止まらない**（D-63）。Discord が落ちていても、みまもりくんは動く。
