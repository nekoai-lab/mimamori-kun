構築手順（15分）

  1. APIキーを取る — aistudio.google.com/apikey（GCPプロジェクト不要・無料枠あり）
  2. clone — git clone https://github.com/nekoai-lab/mimamori-kun.git
  3. .env — cp .env.example .env して GOOGLE_API_KEY= に貼る。
    子の呼び名を変えるなら MIMAMORI_CHILDREN も
  4. 入れる — python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt（版は固定済み）
  5. 起動 — set -a; source .env; set +a
    uvicorn main:app --reload --port 8080
  6. 開く — localhost:8080/kid　親側は /board

確認済み：ADK 1.3.0 / google-genai 2.22.0 で import・Runner のシグネチャ・台帳の状態保持まで通してある。
