# みまもりくん 画面設計 v1.2

最終更新: 2026-09-13 ／ 前提: `要件定義書.md` v1.2

> 画面例の子どもの表示名は「上の子」「下の子」に置き換えてある（public リポジトリのため）。
> 実際の表示名は設定と Firestore に入る。

---

## 0. 画面設計の方針（3つだけ）

**① 初回に見えるのは「今日やること3〜5個」だけ**
グラフ・統計・全体像は必ず2階層目に置く。続かない最大の理由は作り込みすぎ。
**ゲーム性は演出に置き、構造には置かない。**

**② 完了は1タップ、編集は数クリック**
「数クリックで直せるから、1日できなくても投げ出さずに済む」——**リカバリのしやすさ＝継続率。**

**③ 確認画面を新設せず、普段の入力フォームをAIが埋めた状態で出す**
新しい確認UIを覚えさせないこと自体が省力化になる。

## 2. 共通の作り

### 2.1 冒頭の「だれ？」

- アバターと名前の**大きなボタンを2つ**。**PINなし**（D-12）
- 一度選んだら端末に記憶。切り替えは右上のアバターをタップ

### 2.2 色

子どもごとに1色を割り当て、**全画面で一貫させる**。カレンダーに書き出すときも色を分ける。
文字で「◯◯の予定」と読ませない。

### 2.3 下部タブ

| 対象 | タブ |
|---|---|
| 子ども | **今日** ／ 撮る ／ ポイント |
| 上の子 | **今日** ／ 撮る ／ 計画 ／ ポイント |
| 親 | **今日** ／ 承認 ／ 設定 |

### 2.4 承認前のものは子どもに出さない

`status = pending`（親の承認待ち）は、**子どもの「今日やること」に出さない**（実装済み）。

## 3. `/` 撮る

### 3.1 撮影

カメラプレビュー全面＋大きなシャッター。下に「アルバムから」「手で入力」。
撮った直後にサムネイルを出し、**続けて撮れる**。

### 3.2 候補確認 ← ここが体験の急所

```
┌──────────────────────────────┐
│ [原本サムネイル] ←タップで拡大   │  ① 根拠を横に置く
├──────────────────────────────┤
│ ☑ 運動会                      │
│   9/27(土) ・ 下の子 ・ 行事    │
│   [下の子 ▾] ←推定値。1タップで変更│
├──────────────────────────────┤
│ ☐ 遠足  【重複】               │  ② 重複は最初から外す
│   10/3(金) ・ 既に登録あり      │
├──────────────────────────────┤
│ ☑ 個人面談  【日程変更】        │  ③ 旧→新を並べる
│   9/20(土) → 9/27(土)          │
├──────────────────────────────┤
│      [ まとめて登録（2件） ]    │
└──────────────────────────────┘
```

- **原本サムネイルを必ず上に置く**（FR-1.6）
- 「どの子か」は**推定値をデフォルト表示**し、1タップで変更（FR-2.2）
- **完全一致は候補に出さない**（D-33）。並ぶのは 新規・追記・日程変更 の3種だけ
- 登録後トースト：**「2件を登録しました ／ 取り消す」**（一括アンドゥ・10分）

### 3.3 読めなかったとき

- メッセージは具体的に：**「日付に月と日の両方が書かれているか確認してください」**
- ボタンは2つ：**「範囲をなぞって読み直す」** ／ 「手で入力する」

### 3.4 手入力モード（目標：10タップ・20秒）

```
教科  [国語][数学][英語][社会][理科][その他]   ← 1タップ
だれ  [上の子][下の子]                          ← 1タップ
いつ  [今日][明日][あさって][日付を選ぶ]        ← 1タップ
やること  ________________________              ← ここだけ入力
          [ 昨日と同じ ]
                              [ 追加する ]
```

## 4. `/kid` 下の子モード（小学校低学年）

**読み書きゼロで完結させる。**

```
┌──────────────────────────────┐
│   (相棒キャラ) 「きたね！算数からいく？」│
├──────────────────────────────┤
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ │
│  │算数 │ │国語 │ │英語 │ │うわ │ │  ← アイコン＋一言
│  │ ○  │ │ ○  │ │    │ │ばき │ │     タップで完了
│  └────┘ └────┘ └────┘ └────┘ │
├──────────────────────────────┤
│  こんしゅう  ★★★☆☆            │  ← 週の台紙（★5つ）
│  ポイント 24                   │
├──────────────────────────────┤
│  (相棒) 「やったね！1つおわった！」▾ │  ← 下部の吹き出し
└──────────────────────────────┘
```

- カードを**タップするだけで完了**。シールが貼られるアニメーション
- **台紙は週ごと（★5つ・日曜リセット）**
- 台紙が埋まると**紙吹雪**。演出の山は節目（7 / 30 / 100日）に取っておく
- **空状態**：「きょうは やることないよ！」＋相棒が寝ている絵
- **カードの並びは「残り個数」を強調しない**（相棒が数えないことと矛盾するため）

## 5. `/kid` 上の子モード（中学1年）

```
┌──────────────────────────────┐
│ ⚠ このままだと社会が2日たりません │  ← 入らないときだけ
│              [ どれを削る？ ]    │
├──────────────────────────────┤
│ きょう  ▓▓▓▓▓▓░░░  65/90分      │  ← 枠バー
├──────────────────────────────┤
│ ☐ 数学 ワーク p.42-48    (25分) │
│                    [明日に送る] │
│ ☐ 英語 単語 Unit5        (20分) │
│                    [明日に送る] │
│ ☐ 社会 まとめプリント     (20分) │
├──────────────────────────────┤
│          [ 計画を見る → ]       │
├──────────────────────────────┤
│  (相棒) 「のこりの25分、いける？」▾ │
└──────────────────────────────┘
```

- 出すのは**今日の分だけ**。全体像は `/plan`
- 表示は量（p.42-48）、括弧内に所要目安。**内部は分数**（D-26）
- 各行に**「明日に送る」1タップ**。押すと即時再計算＋1行プレビュー

**上の子の「分数」は、相棒の「残りを数えない」に矛盾しない。**
数えないのは**やることの個数**であって、**時間の枠**は計画のための道具。

## 6. `/plan` 計画（上の子）

```
┌──────────────────────────────┐
│  計画 ─── 実績 ┈┈┈             │  ← 乖離グラフ
├──────────────────────────────┤
│ 9/15 月  数学25 英語20  (45/90) │
│ 9/16 火  数学25         (25/30) │  ← 塾の日は枠が小さい
│ 9/17 水  ＜調整日＞      (0/90) │  ← 予備日はグレー
│ 9/18 木  社会40 理科30  (70/90) │
├──────────────────────────────┤
│ 数学 ▓▓▓▓▓▓░░ 68%             │
│ 社会 ▓▓░░░░░░ 22%  ⚠          │
├──────────────────────────────┤
│ [範囲を追加] [優先度] [元に戻す] │
└──────────────────────────────┘
```

- **遅れはグラフの乖離で見せる**
- **予備日はグレーで「調整日」と明示**。未完了はここに集まる
- **日付の移動は「明日に送る」ボタンだけ**（ドラッグは作らない）
- どの操作も**即時再計算**（LLMを経由しない）

## 7. `/board` 親

**1画面目は「例外だけ」。何もなければ空でいい。**

```
┌──────────────────────────────┐
│ 承認まち                        │
│  ・個人面談 9/20→9/27  [承認]   │
│  ・遠足に「水筒」が追加 [追記]   │
│  ・下の子：ギフトカード [確認]   │
├──────────────────────────────┤
│ 気になること                    │
│  ・上の子 社会が2日たりません    │
│  ・下の子 昨日の分が未完了       │
├──────────────────────────────┤
│ 今週  ●上の子 ●下の子          │
│  9/15 ●体操着  ●塾            │
│  9/16 ●集金                    │
├──────────────────────────────┤
│      [ ファイルから取り込む ]   │
└──────────────────────────────┘
```

- **空状態が正常**：「今週、見るものはありません」
- ファイル取り込み → 候補一覧（重複は外れた状態）→ 一括承認
- **版の管理**：「年間予定表（4/10取り込み・18件）」に「改定版をアップロード」。変わった件だけ出る
- 完了した予定は**消えずに件名へ ✓ が付き、一覧から外れる**

### スタンプ（3種類に固定）

| スタンプ | 意味 | 役割 |
|---|---|---|
| **いいね** | 軽い肯定 | 毎日押せる。迷わない |
| **すごい** | 強い称賛 | 節目や難しかった日に |
| **見たよ** | 見ていることを伝える | 評価ではなく「気づいている」を伝える |

**「評価しない」ルールは相棒（アプリ）に対するもので、親には適用しない。**
称賛は人が担い、アプリは記録と提示に徹する。

## 10. 相棒の台詞（「げんき」タイプ）

子ども2人に3タイプを見せて選ばせた結果、**「げんき」タイプ**を採用（2026-09-13）。
ただし `kid_agent.py` に実装済みの**態度ルールが優先**する。元気さは口調で出し、内容はルールに従う。

### 10.1 態度ルール（実装準拠・変更しない）

- **答えを言わない。** ヒントは「場所」と「やり方」まで
- **残りではなく、済んだ数を数える。** 「あと3つ」ではなく「**1つ終わったね**」
  - 数を聞かれたら黙って話を変えず、「数は数えないことにしてる」と一度だけ言って次の1つを示す
- **評価しない。** 「えらい」「すごい」ではなく「**終わったね**」
- **責めない。** 期限を過ぎていても「まだ残ってる。今日やっちゃう？」
- **質問は1つずつ。同じことは2回まで**（3回目は引く）
- **前と同じ文を返さない**
- **秘密を持たない。** 親も見られることを画面に常時表示

### 10.2 台詞表（ルール準拠）

| 場面 | 台詞 |
|---|---|
| ひらいたとき | きたね！算数からいく？ |
| 1つ終わった | やったね！1つおわった！ |
| ぜんぶ終わった | ぜんぶおわった！ |
| 夕方まだ残ってる | まだのこってる！いまやっちゃう？ |
| できなかった日 | きょうはここまで！あしたにまわしとくね |
| おやすみ券が出た | おやすみ券つかっといた！ |
| 撮ってほしい | プリントあった？とっちゃお！ |
| 7日つづいた | 7日つづいた！ |
| 数を聞かれた | 数は数えないことにしてるんだ。つぎはこれ！ |

**上の子だけに出る場面**

| 場面 | 台詞 |
|---|---|
| 入らない警告 | このままだと社会が2日たりない！どれ削る？ |
| 計画を変えた | オッケー！金曜が110分になった！ |
| 雑談から戻す | わかる！……で、のこりの25分いける？ |

### 10.3 トーンの切り替え（1箇所だけ）

**できなかった日はテンションを一段落とす。** 「あしたにまわしとくね」までは元気でよいが、
そこから先の励ましを足さない。

### 10.4 聞くことの3層（実装準拠）

1. **今日のもの**（期限が今日以前）— 「宿題終わった？」
2. **明日の持ち物**（明日の bring / event）— 「明日の忘れ物ない？」
3. **先回り**（3〜7日先の行事・テスト・提出）— 「週末◯◯だけど、進んでる？」

**3つ目が伴走の核。** 言われなくても自分で気づいて聞く。ただし**1回の会話で1つだけ**。

### 10.5 会話の置き場所

**下部の吹き出し**。タップで会話が開き、閉じると今日やることに戻る。
**2往復で今日のことに戻す**という会話設計と、「質問は1つずつ」が揃っている。

## 11. 状態の一覧（全画面共通）

| 状態 | 出し方 |
|---|---|
| **空** | 責めない文で。「きょうはやることないよ！」「今週、見るものはありません」 |
| **読み込み中** | 進捗を出す（「3枚目を読んでいます…」） |
| **読み取り失敗** | 原本のどこを見ればいいかを指示＋なぞり直し／手入力 |
| **オフライン** | 完了マークはローカルに溜めて後で送る。**撮ることは止めない** |
| **承認待ち** | 子ども側には「送りました」で待たされ感を出さない。やることリストには**出さない** |

## 12. この設計で決めたこと

1. 候補確認画面に**原本サムネイルを常設**する
2. 完全一致は候補に出さない。並ぶのは**新規・追記・日程変更の3種だけ**
3. 手入力は**タイトル1行以外すべてボタン**
4. 下の子は**アイコン＋台紙**、上の子は**量＋枠バー**で、同じ `/kid` を作り分ける
5. 「入らない」警告は**出るときだけ**最上部に。常設しない
6. `/board` の1画面目は**例外だけ**。空が正常
7. `/plan` は `/kid` の2階層目に置き、初回では見せない
8. **相棒は「げんき」タイプ**。ただし**実装済みの態度ルールが優先**
9. **台紙は週ごと（★5つ・日曜リセット）**
10. **会話は下部の吹き出し**。独立タブにしない
11. **日付の移動は「明日に送る」ボタンだけ**
12. **スタンプは3種類**。評価を禁じるのは相棒であって、親ではない
13. **承認前（pending）は子どもに出さない**
14. 完了した予定は消さず、**件名に ✓ を付けて一覧から外す**
