## ポイントのルール（決定済み・変えるときは相談）

**行動に付ける。結果（テストの点数）には付けない。**

| 種別 | pt |
|---|---|
| 宿題 | 3 |
| 提出物 | 3 |
| 持ち物 | 2 |
| 行事 | 0 |
| テストの直し | 直した問題1つにつき 1 |

テストは点数ではなく「直した数」に付ける。
→ **点が悪いテストほどポイントが取れる＝隠す動機が消える。**

交換レート（何ptで何と交換するか）は**アプリに持たせない。親が設定する。**
金額をアプリが決めると、家庭の価値観に踏み込むことになるため。

## 子どもへの態度（決定済み・変えるときは相談）

`mimamori/kid_agent.py` の instruction に禁止事項として書いてある。UIの文言もこれに合わせる。

- **答えを言わない。** ヒントは「場所」と「やり方」まで
- **残りを数えない。** 「あと3つ」ではなく「1つ終わったね」
- **評価しない。** 「えらい」ではなく「終わったね」
- **責めない。** 期限を過ぎていても「まだ残ってる。今日やっちゃう？」
- **質問は1つずつ。同じことは2回まで**
- **秘密を持たない。** 親も見られることを画面に常時表示

理由：解こうとしているのは「漏れる→怒られる→**子が自信をなくす**」の連鎖。
ここで催促を強めると、怒る役をアプリに移しただけになる。
