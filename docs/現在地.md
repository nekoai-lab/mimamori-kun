## いまの到達点

**UX の塊 A〜F と、デプロイ前の修正はマージ済み。人によるデプロイ待ち。**

- ログインした子は自分のぶんだけを使い、親の画面・API は親だけが使う。親への一時切替は無操作10分で戻る（#17）
- 撮る→読む→登録→おわった→ごほうびの導線、3テーマ×明暗、相棒・学年と読みの設定が入った（#27〜#41）
- おたよりは通常1回のストリーミング呼び出しで読み、重複照合はコードで行う。写真は長辺1600px、段階表示・写真の追加・再読み取りに対応（#67）。モデルは `gemini-2.5-flash`、thinking budget は512
- 日付があいまいなら登録せず、親に「何月何日？」と聞く。「確認すること」に保存し、3日後以降の確認時に1回だけ知らせ直す（#65）。同じ質問・言い換えと、回答後の同じ予定の二重登録を防ぐ（#70〜#74）
- ごほうびは申請→承認→手渡し。ポイントは完了時に台帳へ記録し、取り消し・再完了でも二重に増やさない（#50・#53）。日程変更・追記では予定の ID を維持する（#54）

## 触るときの固定条件

- **`google-genai` を 2.x に上げない**（`google-adk` 1.3.0 の依存条件は `<2.0.0`）
- `MIMAMORI_DEMO=1` の間はカレンダーに書き込まない。台帳の保存先は別の設定なので、デモでも台帳は保存される
- 開発の読み取りは Vertex AI＋ADC。`GOOGLE_CLOUD_QUOTA_PROJECT` を `GOOGLE_CLOUD_PROJECT` と一致させ、`scripts/dev_server.sh` で起動する
- **実物のプリント・画面写真・予定表は `asetts/` か `samples/real/`（Git管理外）へ。** `samples/` 直下は加工済み・自作のダミーだけ
- 子どもは「上の子」「下の子」と書く。実名・学校名・プロジェクト ID・Webhook・カレンダー ID・SA アドレス・合言葉は public リポジトリに書かない
- **年間予定の正は PDF のキャプチャから起こした版**。学校アプリのテキスト書き出しは使わない（D-52）。実物・期待値は Git 管理外に保管する
